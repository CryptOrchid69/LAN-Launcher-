LAN LAUNCHER - РУССКАЯ ВЕРСИЯ

Это русская локализованная копия LAN Launcher. Используйте LAN Launcher.exe из папки dist.

Перед тестами убедитесь, что Steam установлен, DayZ доступен в библиотеке, а DayZ Server может быть установлен через Steam.

Основной порядок работы:
1. Запустите LAN Launcher от имени администратора, если Windows не дает доступ к папкам Steam.
2. Нажмите УСТАНОВИТЬ и дождитесь завершения подготовки.
3. Нажмите КАРТЫ и выберите карту.
4. Нажмите ЗАПУСК для запуска сервера.
5. Для остановки сервера нажмите СТОП.
6. Для инструкций нажмите ПОМОЩЬ.

Центр знаний можно пополнять своими папками и текстовыми файлами.
